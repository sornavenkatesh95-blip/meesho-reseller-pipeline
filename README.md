## Executive Summary
This repository houses an automated monitoring and alert system engineered for Meesho's Reseller Operations team[cite: 14, 15]. The goal is to replace error-prone, manual reporting spreadsheets with a modular software pipeline that[cite: 16, 17]:
1. Extracts verified performance metrics directly via SQL[cite: 17, 20].
2. Enforces rigorous data validation and boundary checks using Python[cite: 17, 33].
3. Translates metrics into structured, hallucination-free stakeholder narratives[cite: 17, 45, 46].
4. Orchestrates subtasks via a controlled agent runner that enforces mandatory human review before alert dispatch[cite: 17, 54, 56, 59].
